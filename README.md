## DENCO.Outfit\n\nResponsive luxury-fashion discovery storefront built with React and Vite.\n\n### Run locally\n- `npm install`\n- `npm run dev`\n\n### Production build\n- `npm run build`\n\n### Deploy on Vercel\nImport this repository. Select **Vite**, build command `npm run build`, output directory `dist`, install command `npm install`.\n\n### Included in this front-end version\n- Responsive editorial homepage and product grid\n- Category filters, search, price sorting\n- Wishlist and demo shopping bag\n- Style Desk mood recommendations\n- Newsletter form interaction (front-end demo only)\n\n### Not connected yet\nProduct cards, prices and labels are sample demo content, not verified live retailer data. Authentication, persistent accounts, real inventory and ratings, checkout, affiliate tracking, mailing backend and AI-powered styling require further implementation and credentials. Product photos load from Unsplash.
